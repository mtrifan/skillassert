# 05: Quiz player and results page prototype

Type: prototype
Status: open
Blocked by: none

## Question

How should the quiz player and the results page look and feel? Open points that talking cannot settle: question
layout with flag and bookmark affordances, timer presentation, progress, the results page with per-question
explanations, bookmarking and "take a note" from results, and the trial-quiz sign-up prompt. Resolve with the
prototype skill: two or three radically different throwaway variations in one HTML file to react to, then record
the chosen direction here. Throwaway: nothing from it is kept as product code.
