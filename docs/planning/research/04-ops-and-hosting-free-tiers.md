# 04 - Ops and hosting free tiers for skillassert.com

## 1. Header and scope

- **Date read:** 2026-10-29. Every limit below was read from an official pricing, docs, license or terms page on this date. URLs are cited per line.
- **Scope:** object storage for pg_dump, uptime monitors, error tracking, Cloudflare Web Analytics, Cloudflare Pages for Angular, GitHub for a public repository, Caddy automatic HTTPS, VPS hardening baseline.
- **Conventions:** USD unless marked EUR. Hetzner prices exclude VAT. "Free" means the published free tier, not a trial. Third-party pages were used only to locate official pages and are flagged where they are the only source.
- **No recommendation and no winner is given.** Facts and constraints only.

## 3. Topic notes

### 3.1 Object storage for nightly pg_dump
- **R2 free tier:** 10 GB-month Standard storage, 1M Class A, 10M Class B per month, egress free. After that $0.015/GB-month, $4.50/M Class A, $0.36/M Class B. Free tier excludes Infrequent Access. DeleteObject is a free operation. https://developers.cloudflare.com/r2/pricing/ (page dated Oct 26, 2026)
- **R2 S3 API:** endpoint `https://<ACCOUNT_ID>.r2.cloudflarestorage.com`, region `auto`. PutObject, GetObject, ListObjectsV2, DeleteObject and multipart are implemented. Bucket policies, versioning and object tagging are not. https://developers.cloudflare.com/r2/api/s3/api/
- **R2 retention:** lifecycle rules can delete objects after N days via dashboard, Wrangler or S3 API, up to 1,000 rules. Objects are typically removed within 24 hours of expiry. https://developers.cloudflare.com/r2/buckets/object-lifecycles/
- **R2 EU:** the `eu` jurisdiction guarantees EU storage, uses endpoint `https://<ACCOUNT_ID>.eu.r2.cloudflarestorage.com`, is set at bucket creation and cannot be changed. Location hints `weur` and `eeur` are best effort. https://developers.cloudflare.com/r2/reference/data-location/
- **R2 card:** the Get started page says you need "an R2 subscription" and to "Complete the checkout flow". It does not say a card is mandatory. Cloudflare Community threads report a mandatory billing dialog, seen only through search summaries. https://developers.cloudflare.com/r2/get-started/
- **B2 free tier:** first 10 GB free, then $6.95/TB/month. Egress free up to 3x average monthly storage, then $0.01/GB. Class A, B and C calls free. Class D (event notification calls) 2,500 per day free, then $0.004 per 10,000. No minimum file size or minimum duration fees. https://www.backblaze.com/cloud-storage/pricing , https://www.backblaze.com/cloud-storage/transaction-pricing (this page still shows an older $0.005/GB rate)
- **B2 sign-up and API:** sign-up page states "No credit card required." The S3-compatible API supports presigned URLs and SSE-B2 or SSE-C. https://www.backblaze.com/sign-up/b2-cloud-storage-backup-archive , https://www.backblaze.com/docs/cloud-storage-s3-compatible-api
- **B2 retention:** up to 100 lifecycle rules per bucket, applied once per day, hide-then-delete model. Via the S3 API, `Expiration` with `Days` only hides the current version, `NoncurrentVersionExpiration` permanently deletes older versions, and date-based expiry and transitions are unsupported. https://www.backblaze.com/docs/cloud-storage-lifecycle-rules , https://www.backblaze.com/apidocs/s3-put-lifecycle-configuration
- **B2 EU:** region "EU Central" is Amsterdam. It is chosen at account creation, one region per account, cannot be changed, and price does not vary by region. https://www.backblaze.com/docs/cloud-storage-data-regions
- **Hetzner Object Storage:** no free tier. EUR 6.49/month excl. VAT, billed hourly (EUR 0.0104/hour, capped) for each hour at least one bucket exists, even empty. Includes 1 TB storage and 1 TB egress. Ingress and S3 calls are free. 64 kB minimum billable object. Locations FSN1, NBG1, HEL1. https://www.hetzner.com/storage/object-storage/ , https://docs.hetzner.com/storage/object-storage/overview/
- **Hetzner Storage Box:** BX11 is 1 TB at EUR 3.20/month excl. VAT, unlimited traffic, no minimum contract. Protocols: FTP, FTPS, SFTP, SCP, Samba/CIFS, BorgBackup, Restic, Rclone, rsync over SSH, HTTPS, WebDAV. S3 is not listed. Location Germany or Finland. Payment by bank transfer, card, PayPal or SEPA debit. https://www.hetzner.com/storage/storage-box/

- **Better Stack Uptime Free:** $0, "Free for personal projects". 10 monitors and heartbeats in one pool, 1 status page, Slack and email alerts. Docs: check frequency runs "from 3 minutes for free plans to 30 seconds for paid plans". Heartbeats (cron) are on Free. https://betterstack.com/pricing , https://betterstack.com/docs/uptime/check-frequency/
- **Better Stack paid:** +50 monitors $25/month ($21 yearly); +10 heartbeats $20/month ($17 yearly). https://betterstack.com/pricing
- **Cronitor Hacker:** $0 forever. 5 monitors across jobs, checks and heartbeats, fastest check 5 minutes, email and chat alerts (comparison table lists Slack, Discord, Teams, webhooks; the plan card says "Email and Slack alerts"), 1 status page, 1 dashboard user, no SMS. Business: $2/month per monitor plus $5/month per user, 30-second checks, 12-month retention, 14-day trial. https://cronitor.io/pricing

### 3.3 Error tracking
- **Sentry Developer:** $0, 1 user, unlimited projects, 5k errors, 5M spans, 50 replays, 5 GB logs, 30-day lookback. Team is $26/month billed annually with unlimited users, 50k errors and up to 90-day lookback. Data beyond quota and pay-as-you-go budget is dropped and not charged. Spike protection and per-project rate limits exist. https://sentry.io/pricing/ , https://docs.sentry.io/pricing/ , https://docs.sentry.io/pricing/quotas/
- **Sentry region:** US or EU (Frankfurt), chosen when creating the organization. https://docs.sentry.io/organization/data-storage-location/
- **SDKs:** `@sentry/angular` works from Angular 14, and the setup wizard needs Angular 17+. `@sentry/nestjs` needs Node 20.19+, 22.12+ or 23.2+. https://docs.sentry.io/platforms/javascript/guides/angular/ , https://docs.sentry.io/platforms/javascript/guides/nestjs/
- **GlitchTip:** MIT license. Accepts Sentry client SDKs. Self-host needs PostgreSQL 14+ and one service (or web plus worker). Valkey or Redis 7+ is optional. Recommended 512 MB RAM, minimum 256 MB all-in-one, 128 MB plus swap with careful configuration. Hosted: free 1,000 events/month, $15/month for 100k. https://gitlab.com/glitchtip/glitchtip-backend/-/raw/master/LICENSE , https://glitchtip.com/documentation/install/ , https://glitchtip.com/
- **Bugsink:** PolyForm Shield License 1.0.0. Its "Noncompete" clause bars providing a product that competes with it, so it is source-available rather than OSI open source. Sentry-SDK compatible. One container, SQLite by default, MySQL or PostgreSQL supported, no message queue. The Docker guide says PostgreSQL "has not been extensively tested" (https://www.bugsink.com/docs/docker-install/). No RAM figure on the pages read. Hosted: free 15K events/month, 1 user, 5K retained; EUR 16/month for 75K events. https://raw.githubusercontent.com/bugsink/bugsink/main/LICENSE , https://www.bugsink.com/built-to-self-host/ , https://www.bugsink.com/

### 3.4 Cloudflare Web Analytics
- **Cost and privacy:** free. Docs: "does not collect or use your visitors' personal data". Cloudflare's blog says it uses no client-side state such as cookies or localStorage and no fingerprinting. Vendor claim, no audit seen. https://developers.cloudflare.com/web-analytics/about/ , https://blog.cloudflare.com/the-rum-diaries-enabling-web-analytics-by-default/
- **How it is added:** a JS snippet before the closing body tag, automatic setup for Cloudflare-proxied sites, or for Pages one click under Workers & Pages, project, Metrics, Enable. "Cloudflare will automatically add the JavaScript snippet to your Pages site on the next deployment." https://developers.cloudflare.com/web-analytics/get-started/
- **EU setting:** automatic setup offers "Enable, excluding visitor data in the EU". The blog says free domains get Web Analytics by default from 2025-10-15 and that default version excludes EU and UK visitors, changeable in the dashboard. https://developers.cloudflare.com/web-analytics/get-started/ , https://blog.cloudflare.com/the-rum-diaries-enabling-web-analytics-by-default/
- **Reports:** visits, page views, page load time, Core Web Vitals. Dimensions: country, host, path, referer, device type, browser, OS, bot exclusion, navigation type. SPA route changes are tracked via the Soft Navigations API, Navigation API or History API patching. https://developers.cloudflare.com/web-analytics/data-metrics/ , https://developers.cloudflare.com/web-analytics/get-started/web-analytics-spa/
- **Limits:** 10 sites not proxied by Cloudflare, unlimited proxied. Rules: 0 on Free, 5 on Pro. Unsampled beacon data is kept 7 days, then aggregated to about 10%. With a CSP in place, script-src must allow `https://static.cloudflareinsights.com/beacon.min.js`. https://developers.cloudflare.com/web-analytics/limits/ , https://developers.cloudflare.com/web-analytics/faq/

### 3.5 Cloudflare Pages for Angular
- **SPA fallback:** without a top-level `404.html`, Pages "assumes that you are deploying a single-page application" and serves the root (`/`) for any path that is not a static asset. A `404.html` replaces this with custom not-found behavior, using the closest `404.html` up the directory tree. https://developers.cloudflare.com/pages/configuration/serving-pages/
- **Prerendered routes:** "If an HTML file is found with a matching path to the current route requested, Pages will serve it", and requests for `/about/index.html` are redirected to `/about/`. Read with the SPA rule above, a matching prerendered file is served first and unmatched paths fall back to the root document, provided no top-level `404.html` exists. https://developers.cloudflare.com/pages/configuration/serving-pages/
- **`_redirects`:** 2,000 static plus 100 dynamic rules. Status-code rewrites are unsupported. Proxying with a 200 status works for relative URLs only. https://developers.cloudflare.com/pages/configuration/redirects/
- **Workers equivalent:** `assets.not_found_handling = "single-page-application"` serves `/index.html` with 200 for navigation requests matching no asset. `html_handling` defaults to `auto-trailing-slash`. https://developers.cloudflare.com/workers/static-assets/routing/single-page-application/ , https://developers.cloudflare.com/workers/static-assets/routing/advanced/html-handling/
- **Angular output:** `outputMode: "static"` generates prerendered HTML per route with no server. Angular CLI maintainers describe `index.html` as the server-rendered entry point and point to `index.csr.html` as the client-side alternative. https://raw.githubusercontent.com/angular/angular/main/adev/src/content/guide/ssr.md , https://github.com/angular/angular-cli/issues/30458
- **Free limits:** 500 builds/month, 1 build at a time, 20 minute timeout, 20,000 files per site, 25 MiB per file, 100 projects per account, 100 custom domains per project, unlimited preview deployments. Pro: 5,000 builds, 5 concurrent. https://developers.cloudflare.com/pages/platform/limits/ , https://www.cloudflare.com/plans/ (Pro $20/month annual, $25 monthly)
- **Git vs Wrangler:** Git integration supports GitHub and GitLab. Direct Upload uses `npx wrangler pages deploy <dir>`, for example from GitHub Actions. Neither can be switched to the other later. https://developers.cloudflare.com/pages/get-started/direct-upload/ , https://developers.cloudflare.com/pages/configuration/git-integration/
- **Previews:** every branch gets `<hash>.<project>.pages.dev` and an alias `<branch>.<project>.pages.dev`. PR previews work only for PRs from the repo itself. Previews are public by default and can be put behind Cloudflare Access. https://developers.cloudflare.com/pages/configuration/preview-deployments/
- **Angular guide settings:** build `npm run build`, directory `dist/cloudflare`, or `dist/cloudflare/browser` on some Angular versions. https://developers.cloudflare.com/pages/framework-guides/deploy-an-angular-site/
- **Custom domains:** an apex domain must be a zone on the account, with nameservers on Cloudflare, after which Cloudflare creates the CNAME. A subdomain can use a CNAME to `<project>.pages.dev` without moving nameservers, but only after the domain is added in the Pages dashboard, or it returns 522. https://developers.cloudflare.com/pages/configuration/custom-domains/
- **Pages vs Workers:** Pages overview (updated Aug 25, 2026): "Workers supports most Pages use cases... It is Cloudflare's primary platform for building applications. Start new projects with Workers." A migration guide exists and Pages limits are still published (Sep 5, 2026). No removal date was found on pages read. https://developers.cloudflare.com/pages/ , https://developers.cloudflare.com/workers/static-assets/migration-guides/migrate-from-pages/
- **Workers side:** static asset requests are "free and unlimited". Workers Builds Free is 3,000 minutes/month, 1 concurrent build, 20 minute timeout. The Angular guide says `wrangler deploy` auto-detects Angular and sets assets directory `dist/browser`. https://developers.cloudflare.com/workers/static-assets/billing-and-limitations/ , https://developers.cloudflare.com/workers/ci-cd/builds/limits-and-pricing/ , https://developers.cloudflare.com/workers/framework-guides/web-apps/more-web-frameworks/angular/

### 3.6 GitHub for a public repository
- **Actions:** standard GitHub-hosted runners in public repositories are listed under usage that "remains free independently" and does not reduce included compute usage. No minute cap is stated for public repositories. Self-hosted runners are also listed as free. Larger runners are billed. Limits: 6 hours per job, 35 days per workflow run. https://docs.github.com/en/billing/concepts/product-billing/github-actions , https://docs.github.com/en/actions/reference/limits
- **Schedule trigger:** runs only on the default branch, can be delayed at high load such as the start of each hour, and "In a public repository, scheduled workflows are automatically disabled when no repository activity has occurred in 60 days." https://docs.github.com/en/actions/reference/workflows-and-actions/events-that-trigger-workflows
- **GHCR:** "GitHub Packages usage is free for public packages. In addition, data transferred in from any source is free." First publish defaults to private. Publishing from a workflow with `GITHUB_TOKEN` links the package to the repo, otherwise use the `org.opencontainers.image.source` label. Public images can be pulled anonymously. https://docs.github.com/en/billing/concepts/product-billing/github-packages , https://docs.github.com/en/packages/working-with-a-github-packages-registry/working-with-the-container-registry
- **Dependabot:** version updates are "available for... All repositories on GitHub", enabled by a `.github/dependabot.yml` file. Jobs run on GitHub Actions runners. Alerts are available for user-owned and organization-owned repositories. https://docs.github.com/en/code-security/concepts/supply-chain-security/dependabot-version-updates , https://docs.github.com/en/code-security/dependabot/dependabot-alerts/about-dependabot-alerts

### 3.7 Caddy automatic HTTPS
- **Requirements for a public name:** A/AAAA records point at the server, ports 80 and 443 are open externally and bindable by Caddy, the data directory is writable and persistent, and the domain appears in the config. https://caddyserver.com/docs/automatic-https
- **Certificate provider:** public ACME CAs. Defaults are Let's Encrypt, with ZeroSSL as fallback. HTTP challenge needs port 80, TLS-ALPN needs 443, DNS challenge needs no open port but DNS provider credentials. HTTP redirects to HTTPS and renewals are automatic. Experiments should use the staging endpoint, since rate limits "can block your access to HTTPS for up to a week". https://caddyserver.com/docs/automatic-https
- **Storage:** the data directory holds certificates and keys and "must not be treated as a cache". https://caddyserver.com/docs/conventions
- **Docker image:** official image `caddy` on Docker Hub, tags `2`, `2-alpine`, `2.11.7` as of 2026-10-28. Docs: "never use the :latest tag in a production site". Mounts are `/data` and `/config`. Publish `80:80`, `443:443` and `443:443/udp` for HTTP/3, with `--cap-add=NET_ADMIN` for UDP buffers. Mount a folder at `/etc/caddy`, not the Caddyfile itself. https://hub.docker.com/_/caddy
- **Config and license:** a reverse proxy is `reverse_proxy :9000` in a Caddyfile. Apache-2.0. https://caddyserver.com/docs/quick-starts/reverse-proxy , https://github.com/caddyserver/caddy/blob/master/LICENSE

### 3.8 VPS hardening baseline
- **unattended-upgrades:** Ubuntu "will apply security updates automatically... via the unattended-upgrades package, which is installed by default". It runs once per day and can reboot when an update requires it. Config in `/etc/apt/apt.conf.d/20auto-upgrades` and `50unattended-upgrades`. https://documentation.ubuntu.com/server/how-to/software/automatic-updates/
- **ufw:** Hetzner tutorial sets `ufw default deny incoming` and `ufw allow OpenSSH` before enabling, to avoid lockout. https://community.hetzner.com/tutorials/secure-ssh-with-ufw-and-fail2ban-on-ubuntu/
- **ufw and Docker:** published container ports are diverted before ufw's chains, "effectively ignoring your firewall configuration". https://docs.docker.com/engine/network/packet-filtering-firewalls/ Hetzner Cloud Firewalls are free, and a firewall with no rules blocks all inbound traffic. https://docs.hetzner.com/cloud/firewalls/overview/
- **fail2ban:** same Hetzner tutorial installs it, configures `/etc/fail2ban/jail.local` (bantime 1h, findtime 10m, maxretry 5, banaction ufw) with an sshd jail, and notes that on Ubuntu 22.04 the service installs stopped.
- **SSH key-only:** Hetzner: generate an ed25519 key, confirm key login works, then set `PasswordAuthentication no` and `PermitRootLogin no`, testing in a second session first. The page covers dedicated servers; the SSH steps are generic. https://docs.hetzner.com/robot/dedicated-server/getting-started/setting-up-a-bare-metal-server-for-the-first-time/

## 4. Implications for skillassert (facts and constraints, no recommendation)
- **Backup volume:** 14 retained dumps of a few MB each is far below the 10 GB free storage of both R2 and B2. A nightly job is about one upload, one list and one delete per day, far below R2's 1M Class A per month, and B2 Class A, B and C calls are free.
- **Sign-up and cost:** B2 states no card is needed. R2 needs an R2 subscription checkout, with a card reported by users. Hetzner storage has no free tier: EUR 6.49 or EUR 3.20 per month excl. VAT.
- **EU residency:** R2 `eu` jurisdiction is per bucket and immutable. B2 Amsterdam is per account and immutable. Hetzner offers Germany and Finland.
- **Retention timing:** R2 deletes typically within 24 hours of expiry. B2 lifecycle runs daily, and S3-style `Expiration` on B2 only hides versions until a noncurrent-version rule removes them.
- **Backup heartbeat:** UptimeRobot Free has none. Better Stack (10 shared), Cronitor (5 shared), Healthchecks.io (20) and Sentry (1 cron monitor) do. All work by an HTTP request after the job, callable from VPS cron or an Actions workflow.
- **Actions as scheduler:** a backup run from a `schedule` workflow is auto-disabled after 60 days without repo activity in a public repo, and can be delayed at the top of the hour.
- **Probe interval:** free HTTP checks run every 3 minutes (Better Stack) or 5 minutes (UptimeRobot, Cronitor). 30 to 60 seconds is paid.
- **Error tracking:** all three trackers accept Sentry SDKs. Sentry Developer is 1 user and 5k errors, with excess dropped. GlitchTip needs PostgreSQL 14+ and 256 to 512 MB RAM. Bugsink is one container but source-available. `@sentry/nestjs` needs Node 20.19+, which constrains the API base image.
- **Analytics:** Pages one-click adds the snippet at the next deployment. The default setup can exclude EU and UK visitors until changed, which affects an EU audience. Cookie-free is Cloudflare's claim; legal sufficiency was not assessed.
- **Pages build budget:** Free allows 500 Git-triggered builds/month with 1 concurrent build. Direct Upload takes prebuilt assets, for example from GitHub Actions, but cannot later become Git-integrated. Cloudflare steers new projects to Workers, whose Free build allowance is 3,000 minutes.
- **Prerender plus fallback:** Pages serves a matching HTML file first, otherwise the root document, and a top-level `404.html` disables that fallback. Angular CLI maintainers call `index.html` the server-rendered entry point and point to `index.csr.html` as the client-side version. Which of the two sits at the root of a given static build, and how deep links hydrate, was not tested.
- **DNS and TLS:** apex on Pages requires Cloudflare nameservers. The API host needs an A record to the VPS, ports 80 and 443 open, and a persisted Caddy `/data` volume. Cloudflare Full (strict) accepts Let's Encrypt origin certificates (https://developers.cloudflare.com/ssl/origin-configuration/ssl-modes/full-strict/).
- **Registry pulls:** GHCR packages start private, so the VPS needs the package set public or a token with read access. Public repo costs for Actions, GHCR and Dependabot are $0.
- **Firewall:** Docker docs say published container ports are diverted before ufw's chains, so ufw rules alone do not restrict them. Hetzner Cloud Firewall is a separate free control; the page read does not say where it sits relative to the VM.
- **Paid-only items in this note:** Hetzner Object Storage, Hetzner Storage Box, UptimeRobot heartbeat (Solo EUR 10), Sentry Team $26, Cloudflare Pro $20 to $25. Everything else read has a $0 tier.
